## 2. 个人公开仓库

在 GitHub 创建空的公开仓库，例如 `assignment1`。当前项目已有 Git 历史，不需要再次初始化。

交付 ZIP 不含 `.git` 或 `node_modules`。如果使用 ZIP 解压副本，需要先 `git init`，并将下方 `git remote set-url origin ...` 换成 `git remote add origin ...`。直接使用当前目录则按下面命令即可。本版不含覆盖率依赖或报告。

以下 `YOUR_USERNAME` 和仓库名必须替换成真实信息；先确认 origin 指向自己再推送：

```powershell
# 在 VS Code 中打开本项目文件夹，再使用它的集成终端。
.\tools\set-repository.ps1 -RepoUrl 'https://github.com/WoQiuPeter/assignment1.git'
git remote set-url origin https://github.com/WoQiuPeter/assignment1.git
git remote -v
npm ci
npm test
npm run lint
git add .
git commit -m "Implement command-line shopping cart with tests and design"
git branch -M main
git push -u origin main
```

如果 Git 要求身份，填写真实姓名和邮箱。按 GitHub 提示完成账号认证，不要把密码或令牌写进文件。

Windows PowerShell 如果拦截 npm.ps1，改用 npm.cmd。若地址修改脚本也受限，直接在 VS Code 编辑 Dockerfile 的 ARG REPO_URL 即可，无需修改系统策略。

## 3. Docker

安装并启动 Docker，确认 `docker version` 能连接引擎。先推送全部代码和包含真实 URL 的 Dockerfile，再执行：

```powershell
docker build --no-cache -t assignment1 .
docker run --rm -it assignment1
```

验证正常购物、库存不足和结账。保留 `-it` 以进行交互。

在一个新的空目录重新克隆个人公开仓库，再执行 `npm ci`、测试、启动及容器命令，模拟老师批改环境。实际通过后才能在视频中声称容器已验证。
