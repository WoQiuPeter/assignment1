# 完整题目核对与验证记录

依据：用户补充的“作业 1 - 命令行购物车”完整原文，以及此前提供的 A、B 两部分说明。本版不再以“详细规则无法读取”为实现前提。

## 六项功能

| 要求 | 实现 | 验证 |
| --- | --- | --- |
| 产品数组及五个字段 | products.js：id、name、description、price、quantityAvailable | 检查默认商品字段、非法数据和描述缺失 |
| readline 接收 ID 与数量 | cli.js：readline.createInterface；add ID 数量 | 输入流测试及真实 Node 子进程 |
| 数组购物车及三个字段 | 会话对象的 items 数组；productId、quantity、totalPrice | 精确比较新增行、重复合并及修改后的小计 |
| 结账计算与扣减库存 | checkout 校验全部商品后扣 quantityAvailable | 收据、库存、清空与失败不部分扣减 |
| 计算并显示总金额 | getCartSummary 整数分累加，CLI 两位小数显示 | 手算 1.20×2+2.50=4.90；0.10+0.20=0.30 |
| 循环选择，退出/结账例外 | 其他操作后重新显示商品；成功 checkout 或 exit 跳出 | 检查返回界面的次数；结账后不再执行后续输入 |

## 合理假设及对应测试

- 字符串 ID 区分大小写；未知 ID 报错。
- 数量是正安全整数；测试零、负数、小数、NaN、Infinity、字符串和超范围数字。
- 重复商品合并；测试累计超库存和恰好等于库存。
- 加车不扣库存，结账成功才扣；失败保持状态。空车结账错误后可继续。
- price 与 totalPrice 单位为元、最多两位小数；toCents 转成整数分计算，避免二进制小数累加误差。行金额的唯一写入点是添加与修改函数。
- totalPrice 表示单行小计；总价是所有行小计之和。
- 成功结账结束 CLI；业务函数返回收据并清空，因此可在隔离单元测试中检查后续状态。
- 只有单用户内存数据，不含优惠、税费、运费或真实支付；题目未要求这些功能。

## 限制核对

应用仅导入自有 JS 模块、node:readline 等内置模块。package.json 的直接开发依赖名称及版本范围恢复为原模板的七项，未加入其他包。移除 @vitest/coverage-v8、coverage 命令及配置；不提交或引用旧覆盖率报告。

PDF 排版使用项目外的本地文档工具，不属于应用依赖或提交的 JS 源码。运行、测试及验证脚本无需 Python 或其他第三方包。

单元测试覆盖原题给出的六个示例场景，并扩展字段、金额同步、错误状态和 CLI 生命周期。实际结果见验证结果.txt，示例输出见示例运行结果.txt。高测试数量不等于已获老师判定通过。
